# issues
All issues from KoolCraft's warehouse
# Rule
If you want to submit an issue, please use [repository name@type] title as the issue title. Any issues not using this format will be rejected.

For example `[libnbtplusplus@Feature]xxxxxxxxxxxxx`

For example `[KoolMC@Feature;Improve]xxxxxxxxxxxxx`
# Types
issue report type: Feature, Bug, Improve

The `Feature` needs to be something new that hasn’t been added yet.

`Bug` is a problem that happens when something doesn’t work as expected.

`Improve` is an enhancement of existing features to optimize the experience

If you need help, just use the Question type to ask for help in issues, for example `[KoolMC@Question]xxxxxxxxxx`
